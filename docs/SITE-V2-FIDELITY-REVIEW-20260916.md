# SITE V2 样张复刻验收与前两轮复盘

日期：2026-09-16。读者：Milo、Claude。范围：本轮截图与实现的视觉验收；未修改页面代码，未发布。

## 1. 结论

**首屏视觉方向通过；全页复刻暂不通过。** 这版已明显摆脱此前的硬分栏和旧视觉体系，不能继续笼统说它还是 Phase 2.1。但整页密度、导游卡比例和移动端首屏仍有可见差距，尚不能称为完成样张复刻。

这不是重开设计方向。保留当前配色、Inter、真实照片、组件顺序和真实产品边界，集中处理下述四项。

依据：B 图 `assets/reference/site-v4-sample-b-1455.png`；`docs/screens/site-v2-next/` 中同宽全页对比、桌面 Hero、360/375/430 Hero、全页截图及局部；COLLABORATION §38–41；Hero/Moment/SeeHear/Explore/Guides/ui 相关实现。

当前 full-1440.jpg 实际为 **1440×3183**，归一到 1024 宽约 **2263 高**；样张 1024×1536，长 **727px / 47.4%**。§41 的 3187 是此前记录，本次以实际文件为准。高度不是唯一评分，但同宽并排能清楚看出各段累积变松，差额不能主要归因于 Plus 与页脚署名。

## 2. 前两轮为什么没校准方向

责任首先在 GPT 的建议和验收方法，不能只归责于 Claude 没理解。

1. **指导中存在冲突。** FINAL-VISUAL-RECOMMENDATION §3.1 要求连续构图，§3.2 却建议保留旧 #1677FF 和 Manrope，并把深蓝字色视为非关键项。实际是在要求还原样张的同时保留旧视觉惯性。本次 Claude 改成 Inter、海军蓝及参考蓝色，是正确修正，不应回退。
2. **把视觉关系写成形容词，缺少图像对照。** “连续”“紧凑”“同一画面”没有落实为照片起点、融合宽度、标题位置、卡片比例及各段高度的逐项对比。旧结构轻改也能在文字上解释为符合。
3. **验收对象发生偏移。** 地理真实性、段落合并、音频互斥、无溢出都必要，却不能证明“像样张”。前次据这些结果判断进入收口，漏掉了最核心的视觉差异。

更正：旧文档的“可收口”和旧字体/色值建议不再作为本轮复刻达标依据。以用户当前指定的 B 样张及本次视觉核对为准。

## 4. 给 Claude 的最终四项修正

### F01｜恢复各段横带密度

- 桌面 Moment / SeeHear / Guides 当前统一 `py-10 lg:py-12`，每段仅上下 padding 就达 96px。改为逐段参照样张控制，不沿用统一大间距。
- Moment 右面板先保留四个短标题，删减重复的解释性小段；调整左栏宽度与标题字号，使同宽比较接近参考的两行关系。不要将所有正文一起缩小。
- SeeHear 保留真实追问与回答，精简重复文本、气泡内边距及段落上下空白；不制造假输入框或删掉必要答案来硬凑高度。
- 按 B 图各段边界分别量高，乘 1440/1024 后与实际并排。偏差需要指出具体新增内容及其占高，不能只写“实际文案更多”。整页无需硬压到 2160px，但不能无解释地接受多出的约 1023px。

### F02｜重排导游卡，先解决比例

- 当前 `lg:grid-cols-[36fr_57fr]`、104px 圆形头像、窄文字区和长引用共同造成竖卡。样张肖像约占卡宽三分之一，视觉高度明显更大。
- 缩减左侧标题区占比，把空间还给两张卡；采用纵向椭圆/圆角肖像框突出人物，而非继续放大小圆后挤压文本。
- 标题、性格标签、短引用、试听在同一紧凑区域组织；语种清单收成简短信息，完整语言列表可在应用中保留。
- 引用使用已核实内容的短句，试听播放同一句；不要把无来源的新历史事实塞进精简文案。`Start with X` 保留真实入口但降为次要动作。
- 验收看“人物突出、短句好读、按钮不贴边、两卡为横卡”，不是只看卡片等高。手机允许单列，不强迫复制桌面比例。

### F03｜地图高度与图面层次

- Explore 注释写样张约 255px（1024宽）→358px（1440宽），实际 `aspect-[1920/640]` 在1440宽为480px，比自身参照目标高约34%。这是可明确定位的实现偏差。
- 按接近样张的约4:1桌面舞台重新裁切/生成地图，并同步重算点位投影、标签和引线。不能只改容器比例把地图拉扁，也不能为了横向铺开而挪动真实经纬度。
- 让底图退后、站点和站序更突出；优先用现有底图做克制的视觉弱化，不引入新地图服务或复杂交互。署名仍保持清晰。
- 保留三站、示例起点和“站序非逐街导航”的说明。若4:1裁切容不下所有真实点与可读标签，允许略增高度，并在对比中列明原因。

### F04｜窄屏首屏完整信息

- 复核360×812、375×812、430×812：地名、播放按钮、Mia身份及完整第一句均应在首屏可读。当前430通过，360/375未通过。
- 优先减少标题区与按钮组空隙、控制照片展示高度和卡片重叠位置；保持字可读、按钮可点。
- 如改变照片裁切，同步重算图钉锚点，避免再次将标记挂在错误部位。不得仅用 `overflow:hidden` 隐藏问题。
